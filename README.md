# Web Development Lab

Organized multi-page HTML, CSS, and JavaScript project combining the lecture labs (Home, Student Portal, Task Manager, Login, and Register).

## Folder Structure

```text
web/
├── index.html          # Main landing page (Football Academy & Team)
├── pages/
│   ├── portal.html     # Student Portal dashboard (Grid + Flexbox)
│   ├── tasks.html      # Task Manager table & interactive form
│   ├── login.html      # Login page
│   └── register.html   # Registration page with password validation
├── css/
│   ├── main.css        # Shared design system, navbar, forms, tables, footer
│   └── portal.css      # Dashboard-specific layout and responsive sidebar
├── js/
│   └── main.js         # Password match check & live task table submission
└── assets/
    └── image.png       # Academy showcase image
```

## How to Run

Open `index.html` directly in your browser (or serve with VS Code Live Server).
